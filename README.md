# Student Grading System (JavaScript)

## About
A simple JavaScript program to evaluate student marks, assign grades, and generate results with remarks.

## Features
- Validates marks (0–100)
- Assigns grades (A, B, C, F)
- Determines Pass/Fail
- Generates remarks

## Concepts Used
- if-else conditions
- Ternary operator
- Logical operators

## Sample Output
Marks: 85  
Grade: A  
Result: Passed  
Remarks: Excellent
